# CLAUDE.md

## Proyek
Website portofolio Patrik Andryan (dwibahasa ID/EN).
Sumber kebenaran: `BRIEF.md` (desain, struktur, motion, acceptance criteria) dan `CONTENT.md` (semua teks dan data konten).
Jika ada konflik antara asumsi Anda dan kedua dokumen itu, ikuti dokumen dan tanyakan ke Patrik.

## Aturan keras
- Jangan menulis nama perusahaan, klien, atau kreator di mana pun (kode, komentar, nama file, metadata, pesan commit).
- Jangan menambah fitur di luar bagian "Yang TIDAK boleh dibuat" di `BRIEF.md`.
- Teks bertanda `[ISI: ...]` atau `[KONFIRMASI]` di `CONTENT.md` jangan diisi sendiri. Tampilkan teks sementara yang netral dan catat di `TODO.md`.
- Animasi elemen DOM hanya `transform` dan `opacity`. Tidak ada `transition: all`. Hormati `prefers-reduced-motion`. Kanvas/WebGL (latar ruang angkasa, partikel) diizinkan hanya lewat tingkat kualitas `full`/`lite`/`off` dengan pemantau FPS (lihat BRIEF bagian 9).
- Efek hover hanya di `@media (hover: hover) and (pointer: fine)`.
- Tidak ada `.env`, token, atau kunci di repo. Tidak ada backend, database, atau CMS.
- Beranda tema gelap (latar ruang angkasa tetap gelap); halaman studi kasus tema terang (keputusan Patrik, M12; lihat `.light-page`). Maksimal 1 CTA emas per layar.

## Bahasa
Berkomunikasi dengan Patrik dalam Bahasa Indonesia. Kode, nama variabel, dan komentar dalam Bahasa Inggris.

## Alur kerja
- Satu milestone (M0 sampai M6 di `BRIEF.md` bagian 14) per sesi.
- Mulai dengan plan mode, tunggu persetujuan Patrik, lalu kerjakan.
- Commit setelah tiap milestone selesai, dengan pesan commit yang jelas.
- Setelah M0, lengkapi bagian Perintah di bawah.

## Perintah
- Dev: `npm run dev`
- Build: `npm run build` (static export ke `out/`)
- Lint: `npm run lint`
- Pratinjau hasil build: `npm start` (menyajikan `out/` dengan `serve`)
- Tidak ada test runner (belum dibutuhkan sampai M5).

## Arsitektur
- Next.js 16 App Router, **static export** (`output: 'export'`, `trailingSlash`). Tidak ada middleware atau fitur server. Deploy di Vercel (`vercel.json`); `netlify.toml` dipertahankan sebagai cadangan (publish `out`).
- Route berbasis locale: `src/app/[locale]/` (root layout ada di sini, mengatur `<html lang>`), `generateStaticParams` untuk `id` dan `en`, `dynamicParams = false`. `params` adalah Promise (Next 15+).
- Redirect `/` ke `/id/` atau `/en/` dilakukan di `vercel.json` (dan `netlify.toml`) berdasarkan header bahasa, bukan di Next.
- i18n tanpa library: kamus di `content/{id,en}/*.json`, diakses lewat `getDictionary()` di `src/lib/i18n.ts` (alias `@content/*`). Tipe `Dictionary` diturunkan dari JSON `id`, jadi kunci di `en` harus sama.
- Design tokens (BRIEF bagian 7-8) ada di `src/app/globals.css` sebagai CSS variables, dipetakan ke tema Tailwind v4 lewat `@theme inline`. Kelas tipografi: `.t-display`, `.t-h1`..`.t-h4`, `.t-lead`, `.t-metric`, `.t-label`.
- Font self-host: berkas woff2 di `src/fonts/` dimuat lewat `next/font/local` (`src/app/fonts.ts`). Jangan memakai `next/font/google`.
- Hero reveal (M2): `src/components/HeroMotion.tsx` (client, Motion `animate` dari `motion/mini`) mengatur label, kata emas, sub, CTA, nav, dan glow; judul hero naik lewat CSS murni (`hero-title-in`, tanpa JS, agar LCP tidak menunggu hydration). Menyasar elemen lewat atribut `data-hero`, sehingga Hero dan Nav tetap server component. Skrip inline di `<head>` (`src/lib/motionInit.ts`) memasang kelas `reveal-ready` (motion diizinkan) dan `hero-pending` (belum diputar di sesi ini, `sessionStorage` `hero-played`) di `<html>`; CSS menyembunyikan elemen `[data-hero]` dan `[data-reveal]` hanya di bawah kelas itu. Teks selalu ada di DOM. Pengaman CSS-only (`motion-failsafe`, 3 detik) hanya aktif selama `<html>` belum punya kelas `motion-active`, yang dipasang `HeroMotion` dan `RevealOnScroll` saat mount. Kata emas dibuat dua lapis (`.accent-base` + lapis emas `data-hero="gold"`) agar pergeseran warna hanya menganimasikan opacity. Easing memakai kurva `--ease-out` langsung. GSAP sudah dihapus (M8); jangan dipasang lagi, pakai `motion`.
- Reveal section (M2.5): `src/components/RevealOnScroll.tsx` (IntersectionObserver, tanpa GSAP) menambah kelas `is-in` pada elemen `[data-reveal]` (fade + naik 12px, 280ms, sekali). Tambahkan `data-reveal` pada elemen baru yang ingin ikut; jangan pada hero.
- `FlowDiagram` (`src/components/FlowDiagram.tsx`): HTML/CSS agar animasi hanya `transform` dan `opacity`. Varian `mini` dekoratif (`aria-hidden`, tanpa label) dipakai di `ProjectCard`; jumlah node dari `flowSteps` di `content/{id,en}/home.json`. Animasi nyala emas hanya saat hover pointer halus. Varian `full` berlabel menyusul di M3.
- Case study (M3): rute `src/app/[locale]/work/[slug]/`, data per slug di `content/{id,en}/case-studies.json` (judul dan tagline tetap dari `home.json`), layout di `CaseStudyLayout`. Morph kartu ke halaman memakai `<ViewTransition name="card-{num|title|flow}-<slug>" share="morph" default="none">` di kartu dan halaman; `<Link transitionTypes>` (`nav-forward` / `nav-back`) mengatur durasi (400ms / 280ms) lewat CSS di `globals.css`. Isi lain fade lewat `enter="page-in" exit="page-out"`. Jangan beri nama yang sama pada dua elemen di satu halaman. `RevealOnScroll` hanya memutar reveal pada pemuatan pertama; navigasi klien melepas `reveal-ready` supaya target morph tidak tersembunyi. `Nav` hanya memakai `heroReveal` di beranda. Pengujian morph harus di build produksi, bukan `npm run dev`.
- Aksesibilitas (M5): `Nav` punya prop `home` (anchor lokal dan hero fade) dan `pathSuffix` (toggle bahasa tetap di halaman yang sama); header membungkus ke dua baris di mobile tanpa JS. Skip link ada di `[locale]/layout.tsx` dan menuju `<main id="main">`. Kartu Selected Work tidak memakai override `aria-*` (nama aksesibel dari isi kartu; override pernah memicu `label-content-name-mismatch` di axe). Header cache dan keamanan diatur di `vercel.json` dan `netlify.toml`.
- SEO (M6): `buildMetadata()` di `src/lib/seo.ts` membuat metadata per halaman (canonical, hreflang, OG, Twitter); `siteUrl` dan `isProduction` di `src/lib/site.ts` (variabel `SITE_URL`, `VERCEL_PROJECT_PRODUCTION_URL`, `URL`, `VERCEL_ENV`, `CONTEXT`). Selain production, situs `noindex`. `sitemap.ts` dan `robots.ts` statis. 404 dwibahasa di `src/app/global-not-found.tsx` (`experimental.globalNotFound`). Gambar OG dibuat ulang dari `scripts/og.html`.
- Ruang angkasa (M7): `src/components/cosmos/` (`Cosmos.tsx` klien dipasang di `[locale]/layout.tsx` sehingga bertahan antar halaman; `webgl.ts` dimuat dinamis hanya di tingkat `full`; `palettes.ts`). Tingkat dipasang di `<html>` (`cosmos-full|lite|off`) oleh skrip head `motionInit.ts`; pemantau FPS menurunkan resolusi dulu (0.6 ke 0.4), lalu tingkat, disimpan di `sessionStorage` `cosmos-tier`. Section memilih suasana warna lewat `data-cosmos="void|nebula|aurora|ember|supernova"`. Bintang berkelip dan bintang jatuh: tingkat full lewat fungsi `meteor()` di shader (`webgl.ts`), tingkat lite lewat lapisan `.cosmos-stars`/`.cosmos-meteors` CSS (hanya `opacity` dan `transform`, jeda awal 6 detik agar tidak membebani load); off tanpa animasi. `body` transparan agar kanvas (z-index -1) terlihat; warna dasar ada di `html`. `RevealOnScroll` menandai pemuatan pertama dengan counter modul di layout effect (jangan memakai timer).
- Lubang hitam (M9): lintasan satu sumber di `src/components/cosmos/hole.ts` (`holePos(scroll, aspect)`). Tingkat full memakainya sebagai uniform `uHole` di shader `webgl.ts` (lensa, cincin, inti); tingkat lite memakainya di `Cosmos.tsx` `update()` untuk `transform` elemen `.cosmos-hole`. Kecerahan cincin dibatasi agar kontras teks aman.
- Debu bintang dan animasi scroll (M8): `StardustText.tsx` (`DustController`, dipasang di layout) menempelkan efek ke elemen `[data-dust]` lewat `src/lib/dust.ts` (rasterisasi kata ke kanvas, sampel grid, partikel). `data-dust="assemble"` merakit teks dari debu: teks yang sudah di layar saat load mulai berurutan (judul hero lebih dulu, lalu yang lain dengan selisih ±170 ms), teks di bawah layar mulai 10% sebelum terlihat; elemen disembunyikan sejak render pertama lewat `data-dust-state="pending"` (pengaman 3 detik); judul hero (`data-dust-intro`) merakit saat load lalu menguap saat scroll; padding kanvas dibatasi ruang di tepi layar agar halaman tidak pernah melebar; `data-dust="dissolve"` (judul hero) membiarkan teks terlihat sejak render pertama (LCP) dan meniupnya jadi debu mengikuti scroll lewat `scroll()` Motion. Kanvas adalah saudara elemen (bukan anak) dan diberi ukuran akhir sebelum dimasukkan ke DOM (`placeCanvas`), kalau tidak terhitung layout shift. Judul hero menguap dalam 240px scroll (`DISSOLVE_DISTANCE` di `StardustText.tsx`, diukur dari posisi section Hero relatif ke tinggi header). Jumlah partikel: full ±7.000 (DPR maks 1,5), lite ±2.200 (DPR 1), off tanpa debu. Semua judul dan paragraf (kecuali `h1` case study yang terikat Morph, label, nav, dan teks kartu) memakai `data-dust="assemble"`; teks kecil (< 28px) otomatis "cepat" (selesai ±1,3 detik, kanvas dan partikel dibuang setelah selesai, tanpa embusan), teks lebih dari 450 karakter dilewati. ScrollFx/parallax sudah dihapus (tidak dipakai). Kelas `dust-ready` dipasang skrip head selain tingkat off; pengaman CSS 3 detik.
- Intro sinematik (M10): `src/components/sections/Intro.tsx` (server; layar sticky di dalam section tinggi) dan `src/components/IntroFlight.tsx` (klien; `scroll()` Motion dengan `target` section menulis `transform`/`opacity` ke elemen `[data-intro]`; tanpa listener `wheel`). Aktif hanya bila `<html>` punya `intro-on`, dipasang skrip head `motionInit.ts` (motion diizinkan, bukan tingkat off, tanpa `#hash`, path beranda, `sessionStorage` `intro-seen` belum ada); tanpa kelas itu `.intro` `display: none` dan Hero ada di atas. `intro-seen` ditulis saat progres >= 0,98 atau Lewati ditekan. Intro ini satu-satunya section sticky yang diizinkan. Di beranda dengan `intro-on`, header menjadi bar `fixed`: ia memudar keluar saat kamera terbang dan kembali (fade + geser) setelah intro lewat, lewat kelas `intro-nav-hidden` yang diatur `IntroFlight`; kelas `intro-passed` ditambahkan saat progres >= 0,9 dan menahan lubang hitam (shader dan CSS) sampai intro lewat. Karena Hero kini di bawah intro, penguapan judul hero di `StardustText.tsx` diukur dari posisi section Hero relatif ke tinggi header (bukan `scrollY`), dan `HeroMotion.tsx` menunda urutan hero sampai section Hero masuk layar bila `intro-on` (nav tetap muncul di awal).
- Angka Position (M11): `src/components/CountMetric.tsx` (klien) memutar digit seperti odometer saat baris angka masuk layar (sekali; strip digit digeser `translateY` lewat `animate` dari `motion/mini`, easing `easeOut` yang lebih lembut dari kurva default agar terbaca sebagai hitungan). Server merender keadaan akhir (tanpa JS, reduced-motion, tingkat off, dan SEO tetap benar); salinan `sr-only` memuat nilai penuh dan versi visual `aria-hidden`. Nilai di-parse jadi awalan/digit/akhiran; metrik JSON punya field `unit` (kecil, di samping angka). Label dan keterangan Position memakai debu (`Eyebrow dust`, prop `dust` di `CountMetric`).
- Halaman terang dan transisi lubang hitam (M12, M13): `[locale]/work/[slug]/page.tsx` membungkus halaman dengan `<div className="light-page">` yang mengganti token warna (`--bg`, `--text`, `--accent` emas gelap `#8a6100` untuk kontras 5,3:1, dst.) lewat CSS variables, jadi utilitas `text-text`/`bg-bg`/`text-accent` ikut berubah tanpa toggle kelas di `<html>`; warna halaman (`#fafaf9`) ada di `<html>` lewat `html:has(.light-page)` agar lapisan latar (z-index -1) terlihat, dan lapisan gelap beranda disembunyikan di sana. Cosmos menjeda shader WebGL bila `.light-page` ada. **Latar bergerak terang (M13)**: `Cosmos.tsx` merender `.cosmos-light-wrap` (dua kelompok orb pastel `lp-group-a/b` yang melayang berlawanan, lima suasana `lp-<mood>-<a|b>` yang crossfade lewat `opacity`; suasana dipilih oleh `data-cosmos` per section studi kasus, section terdalam menang), dan `LightMotes.tsx` (kanvas 2D debu emas, hanya tingkat full, 30 fps, berhenti sendiri bila lambat). Keduanya memudar masuk setelah transisi (`ls-in`). Kontras latar terukur: luminans minimum 0,86 (teks redup 7:1). **Transisi masuk ke studi kasus**: tautan maju (kartu dan "Proyek berikutnya") memakai `BlackHoleLink` -> `src/lib/blackHole.ts`: elemen `.bh-curtain` dan `.bh-portal` (di layout) dianimasikan dengan Web Animations API (halaman lama diperkecil-dibesarkan sedikit, cakram hitam membesar, tirai hitam menutup), baru lalu `router.push`; `BlackHoleArrive` (di halaman studi kasus) mengangkat tirai setelah halaman baru terpasang. Kelas `bh-nav` di `<html>` menyembunyikan `::view-transition` dan memblokir klik; `bh-start`/`bh-end` menjeda shader; `popstate` membatalkan push yang tertunda. **Jangan** kembali ke View Transition pseudo-element untuk efek ini: urutan cat-nya terbukti menampilkan halaman terang sebelum lubang hitam. **Kembali (M14, lubang putih)**: mesin yang sama di `blackHole.ts` dengan jenis `white` (kelas `bh-white` di `<html>`: tirai `#fafaf9`, cakram putih bercincin emas). `BackLink` (tombol Kembali di studi kasus) menyusutkan halaman terang, memancarkan cahaya, lalu `router.push`; `BackTransition` (di layout) menangani Back/Forward browser lewat `popstate` bila `.light-page` sedang tampil: karena navigasi tidak bisa ditunda, tirai dipasang seketika lewat `style.opacity` (sinkron, sebelum swap) dan baru diangkat oleh `BlackHoleArrive` (dipasang di beranda dan studi kasus), yang juga menskalakan halaman baru dari 1,06 ke 1. Animasi pengangkat memakai `fill: "both"` agar tirai tidak berkedip saat jeda. Morph kartu `nav-back` hanya jadi cadangan (reduced-motion, tingkat off, klik bermodifikasi). Hanya `transform` dan `opacity`.
- Performa debu (M13): `getContext("2d", { willReadFrequently: true })` harus ada di panggilan PERTAMA (`StardustText.attach`); tanpa itu `getImageData` membaca balik dari GPU dan memblokir 3 detik. Kanvas dibatasi ke kotak teks sebenarnya (`textBox` di `dust.ts`), teks kecil memakai kanvas ringkas (`COMPACT`) dan DPR 1.
- Intro (M12): navbar beranda (`header[data-nav]`) tersembunyi selama intro (`.intro-on:not(.intro-passed)`) lalu memudar masuk lewat CSS; `HeroMotion` melepas atribut `data-hero` dari nav bila `intro-on`. Baris sapaan `intro.welcome` dirakit dari debu seperti teks lain.
- Kursor cahaya (M9): `src/components/CursorGlow.tsx` (dipasang di layout) membuat dua elemen `fixed` (inti dan cahaya) hanya untuk mouse dan bukan tingkat `off`; kursor asli tidak disembunyikan. Hanya `transform` dan `opacity`; loop rAF berhenti sendiri saat pointer diam. Elemen yang membuat cahaya membesar: `a, button, [role="button"], .project-card`.
- Tipografi: judul besar (Display, H1, H2) weight 300, H3 400, label mono tracking 0.16em. Space Grotesk dimuat 300/400/500, JetBrains Mono 500.
